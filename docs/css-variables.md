# CSS変数 — 仕様書

**ファイル:** `src/app/styles/common.css`

プロジェクト全体で使う CSS カスタムプロパティ。ライト/ダークモード両対応。

---

## カラー

| 変数 | ライト | ダーク | 用途 |
|---|---|---|---|
| `--bg` | `#ffffff` | `#0d1a0d` | ページ・カード背景 |
| `--surface` | `#f8faf8` | `#172017` | セクション背景 |
| `--surface-alt` | `rgba(255,255,255,0.5)` | `rgba(0,0,0,0.2)` | 薄い背景 |
| `--text` | `#1a2e1a` | `#e8f5e8` | メインテキスト |
| `--muted` | `#4a6a4a` | `#8ab08a` | サブテキスト |
| `--placeholder` | `#9ab09a` | `#4a6a4a` | placeholder・ラベル |
| `--label-muted` | `#7a9a7a` | `#5a7a5a` | ラベル補助 |
| `--primary` | `#16a34a` | `#4ade80` | ブランドカラー（緑） |
| `--error` | `#dc2626` | `#f87171` | エラーメッセージ |
| `--warning` | `#d97706` | `#fbbf24` | 警告メッセージ |
| `--link-color` | `#1e40af` | `#93c5fd` | リンク |

## グラデーション

| 変数 | 説明 |
|---|---|
| `--brand-grad-start` | ブランドグラデーション開始色 (`#16a34a`) |
| `--brand-grad-end` | ブランドグラデーション終了色 (`#064e3b`) |
| `--page-bg` | ページ背景グラデーション（薄いグリーン） |
| `--btn-grad` | ボタン背景グラデーション |

## ボーダー・シャドウ

| 変数 | ライト | 用途 |
|---|---|---|
| `--border` | `rgba(0,0,0,0.06)` | 薄いボーダー |
| `--border-strong` | `rgba(0,0,0,0.08)` | 強めのボーダー（入力欄など） |
| `--shadow` | `rgba(10,40,10,0.08)` | ドロップシャドウ |
| `--shadow-card` | `rgba(0,0,0,0.04)` | カードのシャドウ |
| `--focus-border` | `#059669` | フォーカスリング色 |

## ヒーロー・フッター

| 変数 | 値 |
|---|---|
| `--hero-bg` | `rgba(6,40,20,0.85)` |
| `--hero-solid` | `#064e3b` |
| `--footer-bg` | `#1a3a2a` |

## レイアウト

| 変数 | 値 | 説明 |
|---|---|---|
| `--max-width` | `1200px` | コンテナ最大幅 |
| `--gutter-x` | `2rem` | 左右の余白 |
| `--container-radius` | `12px` | カードの角丸 |

## ユーティリティクラス

| クラス | 説明 |
|---|---|
| `.u-container` | `max-width: var(--max-width)` + 自動センタリング |
| `.btn` | ボタン共通スタイル（シャイン疑似要素付き） |
| `.sr-only` | スクリーンリーダーのみ表示（視覚非表示） |

## 共通アニメーション

| キーフレーム | 内容 |
|---|---|
| `fadeInUp` | `opacity: 0; translateY(20px)` → `opacity: 1; translateY(0)` |
| `spin` | 0〜360度回転（ローディングスピナー用） |

### 使用例（fadeInUp）

```css
.myElement {
  animation: fadeInUp 0.6s ease both;
}
```
